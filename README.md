## ⚙️ Architecture & Design Philosophy

CoreShadow represents an engineered digital environment combining:
- **Cinematic Monochrome Visual Identity**: Built on a strict perceptual palette (`#080808` Void, `#101010` Obsidian, `#191919` Graphite, `#303030` Steel, `#B7B7B7` Silver, `#F2F2F2` Text) with zero generic AI purple or saturated neon glows.
- **Mathematical Mechanical Gear Engine**: Custom 2D Canvas gear train rendering mathematically accurate involute gear tooth geometry, opposite angular velocity meshing, and subtle metallic radial gradients.
- **Ultra-Lean Performance**: Zero heavy dependencies, zero runtime bloat. Sub-0.8s LCP, 60 FPS hardware-accelerated animations, and instant static execution.
- **Accessibility & Complete Interaction**: Full keyboard navigation, visible contrast compliance (WCAG 2.2 AA), screen-reader aria landmarks, and respect for `prefers-reduced-motion`.

## 💻 Local Development

No build tooling or compiler required. Double-click `index.html` to run directly in any modern browser, or launch a local preview server:

```bash
# Clone the repository
git clone https://github.com/CodeStrikerMayank/Mineart.git

# Enter the directory
cd Mineart

# Run preview server
npm start
# or
npx serve .
```
